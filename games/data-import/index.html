Incident INC-2026-0902  Severity: High 

After-hours VPN sign-in followed by a download burst on the FSB shared drive · analyst on duty: you
At 02:31 someone signed in to the VPN from outside the United States after a string of failed attempts, then spent 27 minutes on the shared drive. We do not yet know whose account it was or what was taken. Security tools export their logs as CSV and JSON files; for this exercise, those exports are served at a URL so you can practice importing them in R.

Rules of engagement

Browser first, R second. Every piece of evidence below is a small file at a URL. Before you import any of them, open the URL in a new browser tab and read the raw file with your own eyes. You will see the CSV or JSON exactly as R receives it, and you will usually spot the answer before you write a line of code. Then import it in R to confirm.

Every reply is data. A wrong key or code does not produce an error; it returns JSON with a hint. Open it, read it, import it.

Work in pairs, in a Rmd file.

Evidence chain

1

Identify the compromised account

Last night's VPN sign-in log, a CSV. Open it in a new tab and read it, then import it. Which account shows a password-guessing pattern: the most failed attempts before a successful sign-in?

logins = readr::read_csv("https://isa401-import-heist.vercel.app/api/stage1")
2

Scope the damage

That account name replaces ACCOUNT and unseals the account's shared-drive activity, a JSON file. Open it in a new tab (sealed until you add the key, and the reply tells you how), then import it. How many of the events in log$events are DOWNLOADs?

log = jsonlite::fromJSON("https://isa401-import-heist.vercel.app/api/stage2?key=ACCOUNT")
3

Close the ticket

The download count replaces NUMBER. Open it in a new tab with your code, then import it. On CLEARED, read the incident report: it links a replay of the incident. Watch it, then post your team name on the Menti wall.

jsonlite::fromJSON("https://isa401-import-heist.vercel.app/api/finish?code=NUMBER")
