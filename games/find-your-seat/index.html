How this works
1. In RStudio, open markdowns/class05.Rmd, add a code chunk, and run this line once. It creates an object called campus:
campus = jsonlite::fromJSON(
  "https://isa401-find-your-seat.vercel.app/campus.json")
2. Tap your seat on the plan below (Level 0).
3. Answer Levels 1, 2, and 3 in order. Each answer is one value you pull out of campus with brackets in R. Type the value in the box and press Check. A wrong answer shows a hint; nothing locks.
4. Look at the projector: your seat changes color each time you clear a level.
Stuck at the start? Run campus$briefing and read it. Start over on this device
Level 0   Where are you sitting?
Section Front of the room (screens) is at the top.
Tap the circle for the computer you are at. On a phone, scroll the plan sideways to reach the right half. L is left of the aisle, R is right; the row number is 1 at the front; seats count 1 to 7 from left to right. Tap another circle to change it.
Level 1   The business school
What to find: campus is a named list: a briefing and five very different places. One of the places is the business school. Its element holds a field called code. Type that code.
Hint: look at what campus holds before you reach into it (str() with max.level = 1 keeps it short). Then remember the Pepper Shaker rule when you open the element you want. The code is capital letters, no spaces.
Level 2   The floor
What to find: inside the business school's element, floors is a named list with one element per floor. Room 2050 is on one of them. That floor has a field called sections, the number of Fall 2026 sections meeting on the whole floor. Type that number.
Hint: a room number tells you its floor. Reach into the business school, then into its floors, and pick the floor by name. On a named list, the second element and the element named "2" are not the same thing.
Level 3   The room
What to find: the same floor has a rooms element, a data frame with one row per room and a column isa_sections. Type the isa_sections value on the row where room is "2050".
Hint: it is a data frame, so the Class 04 row rule applies: a logical test on one column picks the row, then read the column you want. Saving the data frame to a short name first makes the line easier to type. The room column is text.
The Pepper Shaker rule
One bracket keeps the shaker: x["a"] is still a list, so x["a"]$field gives NULL. Two brackets open it: x[["a"]] is the thing inside, and x[["a"]]$field works. On a named list, x[[2]] and x[["2"]] can be different elements.

The trip you just made, in brackets
campus = jsonlite::fromJSON(
  "https://isa401-find-your-seat.vercel.app/campus.json")
campus[["Farmer"]]$code                      # "MUFSB"
campus$Farmer$floors[["2"]]$sections        # N
r = campus$Farmer$floors[["2"]]$rooms
r$isa_sections[r$room == "2050"]             # N
Monday: the same trip in dplyr
campus$Farmer$floors[["2"]]$rooms |>
  filter(room == "2050") |>
  pull(isa_sections)                                 # N
Same question, no brackets. filter() is the row rule, pull() opens the column.
