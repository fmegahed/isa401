    How This Data Got Here (Data Lineage)
    Step 1
    Job Board APIs
    ChatISA Job Scout queries the ActiveJobs and USAJobs APIs every week. The APIs return semi-structured JSON.
    →
    Step 2
    De-duplication
    The same job appears on multiple boards. A fingerprint (company + title + state) removes duplicates.
    →
    Step 3
    LLM Skill Tagging
    An AI model reads each unstructured job description and tags skills as required or preferred.
    →
    Step 4
    SQLite Database
    Clean records are stored as structured rows in a database table (one row = one posting).
    →
    Step 5
    This Dashboard
    The table is exported to JSON and embedded here so you can filter, map, and chart it.
